# LAB 08 — Joins Part 01: INNER, LEFT, RIGHT Joins

## Purpose
The purpose of this lab is to understand how SQL JOIN operations combine related data from multiple tables.

## Topics Covered
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Table relationships
- NULL values in joins
- JOIN conditions

## Work Performed
- Created a Library database
- Connected books with authors
- Connected members with loans
- Retrieved matching records using INNER JOIN
- Retrieved unmatched records using LEFT and RIGHT JOIN
- Identified authors or members without related records

## Objective
To understand how JOIN operations are used to retrieve related information from multiple relational tables.
