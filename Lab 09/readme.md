# LAB 09 — Joins Part 02: Multi-table Joins & Combined Challenges

## Purpose
The purpose of this lab is to apply JOIN operations across multiple related tables to solve more complex database queries.

## Topics Covered
- Multi-table JOINs
- INNER JOIN
- LEFT JOIN
- UNION
- NULL conditions
- Combined queries
- Multiple table relationships

## Work Performed
- Joined Loan, Member, Book, and Author tables
- Retrieved currently borrowed books
- Listed all books including never-borrowed books
- Identified authors whose books were never borrowed
- Retrieved members who borrowed books by Pakistani authors
- Practiced FULL OUTER JOIN emulation using UNION

## Objective
To develop the ability to solve real-world database problems using multiple-table JOIN queries.
