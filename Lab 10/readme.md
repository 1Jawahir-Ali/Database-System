# LAB 10 — Scalar Functions Part 01: String Functions

## Purpose
The purpose of this lab is to manipulate and format text data using SQL string functions.

## Topics Covered
- TRIM
- UPPER
- LOWER
- SUBSTRING_INDEX
- LEFT
- CONCAT
- REPLACE
- String formatting

## Work Performed
- Created an Employee database
- Cleaned employee names
- Converted names to uppercase
- Extracted usernames from email addresses
- Masked phone numbers
- Generated corporate email addresses

## Objective
To understand how SQL string functions can be used to clean, transform, extract, and format text data.
