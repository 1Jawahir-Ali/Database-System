# LAB 11 — Scalar Functions Part 02: Numeric & Date/Time Functions

## Purpose
The purpose of this lab is to perform numerical calculations and date/time manipulation using SQL scalar functions.

## Topics Covered
- ROUND
- FLOOR
- TIMESTAMPDIFF
- CURDATE
- DATE_FORMAT
- YEAR
- Date and numeric calculations

## Work Performed
- Calculated salary increases
- Rounded salaries to the nearest thousand
- Calculated employee age
- Calculated years of service
- Formatted hiring dates
- Filtered employees based on hiring year
- Created combined employee profiles

## Objective
To learn how numeric and date/time functions can be used for calculations, formatting, and data analysis.
