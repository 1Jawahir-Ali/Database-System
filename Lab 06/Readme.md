# LAB 06 — Filters Part 01: Comparison & Logical Operators

## Purpose
The purpose of this lab is to retrieve specific records from a database using comparison and logical operators.

## Topics Covered
- WHERE clause
- Comparison operators
- Logical operators
- Greater than conditions
- AND / OR
- ORDER BY
- LIMIT

## Work Performed
- Created and used an Online Bookstore database
- Filtered books according to price
- Retrieved books based on stock availability
- Used logical conditions for filtering
- Sorted query results
- Retrieved the top records using LIMIT

## Objective
To learn how to filter and organize database records according to specific conditions.
