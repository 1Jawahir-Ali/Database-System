# Database Systems Lab 05 - SQL Filters Assignment
## Description
This lab task is based on an Online Bookstore database system.  
The purpose of this assignment is to practice SQL filtering operations using different SQL clauses and conditions.

The database contains a single table named `Book` which stores information about books including:
- Book ID
- Title
- Author
- Genre
- Price
- Stock Quantity
- Published Year
- Publisher
- Language

The task includes creating the database, inserting sample records, and solving 10 SQL filter queries.

## Topics Covered

The following SQL concepts are used in this assignment:

- SELECT statement
- WHERE clause
- ORDER BY
- BETWEEN operator
- LIKE operator
- IN operator
- NULL handling
- LIMIT clause
- Logical operators (AND, OR)
