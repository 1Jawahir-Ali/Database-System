# LAB 03 — Keys and Queries

## Purpose
The purpose of this lab is to understand database keys, constraints, basic SQL queries, and table modification operations.

## Topics Covered
- Primary Key
- Foreign Key
- Candidate Key
- Alternate Key
- Composite Key
- UNIQUE and NOT NULL constraints
- SELECT, UPDATE, DELETE
- ALTER TABLE
- JOIN operations
- TRUNCATE and DROP

## Work Performed
- Created a university database
- Created Students, Departments, Courses, Instructors, and Enrollments tables
- Applied different constraints and keys
- Inserted and queried data
- Performed UPDATE and DELETE operations
- Added a new column using ALTER TABLE
- Practiced JOIN queries

## Objective
To develop a practical understanding of database keys, constraints, and fundamental SQL operations.
